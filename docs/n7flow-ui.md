# N7Flow: русификация и совместимость

Это пользовательское название и UI-слой поверх совместимого Forkop.
Не менять UCI, procd, CLI, маршруты LuCI, backend-теги и директории в рамках
визуального ребрендинга — они используются установленной версией роутера.

## Сборка

    cd fe-app-forkop
    yarn install --frozen-lockfile
    yarn build
    yarn locales:actualize

При сборке OpenWrt каталог luci-app-forkop/po/ru/forkop.po превращается в
/usr/lib/lua/luci/i18n/forkop.ru.lmo пакета luci-i18n-forkop-ru.
Сам luci-app-forkop не включает этот язык без отдельного пакета перевода.
Установка статических JS, пункта меню и LMO не требует рестарта Forkop/sing-box.

Вкладки UI: Правила · Серверы · Настройки · Диагностика · Обзор · Соединения ·
Обновления. Названия пользовательских правил, домены и адреса серверов
не переводятся и не изменяются автоматически.
